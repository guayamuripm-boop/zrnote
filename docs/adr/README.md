# Registros de decisiones de arquitectura (ADR)

Un ADR fija **por qué** se tomó una decisión, para no reabrirla sin saber lo que costó. Formato: contexto → decisión → consecuencias. Son inmutables: si cambia la decisión, se escribe uno nuevo que sustituye al anterior.

| [0003](0003-repository-layout.md) | Organización del repositorio y de la documentación | Aceptada |
